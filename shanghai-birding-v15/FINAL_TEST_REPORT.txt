Shanghai Birding MVP - Final Regression Report (v15)

Scope
- eBird is the default online hotspot data source for Shanghai (CN-31).
- The provided eBird API key is embedded as the default application key; Settings can still override it.
- Same-place hotspot records are merged before same-place/same-species aggregation.
- Same-place/same-species repeated observations retain the latest observation timestamp while preserving aggregate counts.
